# Code of Conduct

## Our Pledge

We want this project to be a friendly place for everyone, no matter their age, background, identity, experience level, or anything else. We pledge to treat each other with respect and keep participation harassment-free.

## Our Standards

Things that help keep the community healthy:

* Being kind and respectful, even when you disagree
* Giving and accepting feedback gracefully
* Owning up to mistakes and learning from them
* Thinking about what's best for the whole community

Things that are not okay:

* Insults, trolling, or personal attacks
* Sexualized language or unwelcome attention
* Harassment, public or private
* Sharing someone's private information without permission
* Anything else that would be considered inappropriate in a professional setting

## Enforcement Responsibilities

The project maintainers are responsible for clarifying these standards and will take fair and appropriate action when behavior is unacceptable. They can remove, edit, or reject comments, commits, code, issues, and other contributions that don't follow this Code of Conduct, and will explain why when they do.

## Scope

This Code of Conduct applies in all project spaces, including the repository, issues, and pull requests. It also applies when someone is officially representing the project in public.

## Enforcement

If you see or experience unacceptable behavior, report it to the maintainers by opening a GitHub issue or contacting the repository owner through their GitHub profile. All reports will be reviewed promptly and fairly, and the reporter's privacy will be respected.

## Enforcement Guidelines

Maintainers will follow these steps when deciding on consequences:

1. **Correction:** A private message explaining what was wrong, and possibly a request for a public apology. Used for minor, one-off issues.
2. **Warning:** A formal warning for a single serious incident or repeated behavior, with a period of no interaction with the people involved.
3. **Temporary Ban:** A temporary ban from the project for serious or sustained misconduct.
4. **Permanent Ban:** A permanent ban for a pattern of violations, harassment, or aggression toward others.
